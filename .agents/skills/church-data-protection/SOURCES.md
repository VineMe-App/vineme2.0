# Legal sources register

#### When to use this file

Read this before relying on a legal rule, deadline or transfer mechanism from the topic files, and when reviewing the skill.

Laws, guidance and adequacy decisions change. This file lists each claim in the topic files that can go out of date, the official page to check it against, and when it was last checked.

- **Moving?** "Yes" means the rule is changing or being brought in now. Check it before relying on it, whatever the date says.
- **Last checked** is the date someone compared the claim with the official source (YYYY-MM-DD). `not yet verified` means the claim was written from general knowledge and nobody has checked it yet.
- Review every entry at least every 6 months. The `data-protection-sources-review` GitHub Actions workflow runs each quarter, and if any entry is due it opens an issue labelled `data-protection-review` and assigns it to the reviewer named in the workflow.
- When you review an entry, update the topic file and the date here in the same PR. Keep each row on one line and don't use `|` inside a cell, because the workflow parses this table.
